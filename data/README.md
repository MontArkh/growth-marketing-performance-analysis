# Dataset

This project uses the Social Media Advertisement Performance
synthetic dataset.

The original data consists of four relational tables:

| Table | Grain |
|---|---|
| campaigns | One row per campaign |
| ads | One row per advertisement |
| users | One row per user record |
| ad_events | One row per advertising event |

Dataset size:

- 50 campaigns
- 200 ads
- 10,000 user records
- 400,000 advertising events

Raw CSV files are not included in this repository.
